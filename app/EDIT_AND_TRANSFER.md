# راهنمای ویرایش و انتقال نرم‌افزار

## بخش ۱: ویرایش محتوا و نرم‌افزار

### ۱-۱. تغییر متن درس‌ها
1. فایل Markdown مربوط را در پوشهٔ ماژول ویرایش کنید، مثلاً `13_GPC_Catalase_Positive/01_Differential_Tables.md`. ویرایش مستقیم در GitHub هم درست است.
2. محتوای نرم‌افزار را دوباره بسازید:
   ```bash
   python3 app/build/build_content.py
   ```
3. اگر نرم‌افزار باز است، با **Ctrl+R** تغییر را ببینید.
4. کامیت و push کنید.

> ⚠️ اگر مرحلهٔ ۲ انجام نشود، تغییر در درس‌نامهٔ GitHub دیده می‌شود ولی در نرم‌افزار دیده نمی‌شود.
> اگر در GitHub ویرایش کرده‌اید، اول `git pull` و بعد مرحلهٔ ۲ را انجام دهید.

### ۱-۲. سناریوها و پاسخ‌ها
- در فایل‌های `*_Scenarios.md` و `*_Answers.md` با همین قالب بنویسید:
  - `### سناریو N — عنوان` (برای سطح دشواری، یکی از 🟢 🟡 🔴 را پس از شماره بگذارید)
  - `### پاسخ N — عنوان`
- شمارهٔ سناریو و پاسخ باید یکی باشد.
- سپس `build_content.py` را اجرا کنید.

### ۱-۳. افزودن تصویر
1. عکس را در `Assets/images/` همان ماژول بگذارید.
2. یک سطر به جدول `Assets/CREDITS.md` اضافه کنید: شماره، فایل، زیرنویس، سازنده، منبع، مجوز.
3. شکل را در متن درج کنید.
4. `build_content.py` را اجرا کنید.

پرسش‌های آزمون تصویری خودکار از زیرنویس‌ها ساخته می‌شوند. قواعد تصویر: [Shared/Figures/Image_Policy.md](../Shared/Figures/Image_Policy.md).

### ۱-۴. فیلم‌ها
- فایل [`assets/js/videos.js`](assets/js/videos.js) را ویرایش کنید. برای هر فیلم یک سطر هست: `id` (شناسهٔ ویدیو در YouTube)، `title`، `channel` و `note` (یادداشت فارسی).
- این فایل به build نیاز ندارد.

### ۱-۵. ظاهر و رفتار برنامه
- رنگ، قلم و چیدمان در [`assets/css/app.css`](assets/css/app.css) است.
- منطق برنامه (صفحه‌ها، آزمون، پرسش از Claude) در [`assets/js/app.js`](assets/js/app.js) است.
- پیشنهاد: این تغییرها را با Claude Code انجام دهید و پیش از push، برنامه را باز کنید و آزمایش کنید.

### نکته‌ها
- build فقط **Python 3** لازم دارد. روی لینوکس معمولاً نصب است، ولی روی ویندوز باید از [python.org](https://www.python.org/downloads/) نصب شود.
- فایل `assets/js/content.js` خودکار ساخته می‌شود؛ آن را دستی ویرایش نکنید.

## بخش ۲: انتقال به کامپیوتر دیگر

### ۲-۱. آوردن پوشه (یکی از این دو راه)
- **از GitHub:**
  ```bash
  git clone https://github.com/raminabiri/course-clinical-microbiology.git
  ```
  بدون Git هم می‌شود: صفحهٔ مخزن ← دکمهٔ **Code** ← **Download ZIP** و بعد از حالت فشرده خارج کنید.
- **با هارد یا فلش:** کل پوشهٔ مخزن را کپی کنید، نه فقط پوشهٔ `app`، چون تصاویر در پوشهٔ ماژول‌هاست.

### ۲-۲. ساختن آیکون (یک‌بار در هر کامپیوتر)
- **ویندوز:** روی `app\install-windows.bat` دوبار کلیک کنید تا آیکون روی **دسکتاپ** و در **منوی Start** ساخته شود.
- **لینوکس:**
  ```bash
  bash app/install-linux.sh
  ```
  آیکون روی دسکتاپ و در منوی برنامه‌ها ساخته می‌شود. اگر از فلش کپی کرده‌اید، حتماً با `bash` اجرا کنید، چون مجوز اجرای فایل ممکن است از بین رفته باشد.
- **مرورگر لازم:** ویندوز: Microsoft Edge (روی ویندوز ۱۰ و ۱۱ از پیش نصب است) یا Chrome. لینوکس: Chrome، Chromium، Edge یا Brave.

### ۲-۳. پیشرفت مطالعه (اختیاری)
- در کامپیوتر قبلی: **تنظیمات ← ذخیرهٔ فایل پیشرفت**
- در کامپیوتر جدید: **تنظیمات ← وارد کردن فایل**

پیشرفت شامل صفحه‌های خوانده‌شده، نشان‌ها، یادداشت‌ها و نتایج آزمون است.

### ۲-۴. کلید API
کلید عمداً منتقل نمی‌شود. در کامپیوتر جدید دوباره در **تنظیمات** واردش کنید.

### ۲-۵. به‌روز نگه داشتن نسخه‌های دیگر
- در هر کامپیوتر، داخل پوشهٔ مخزن `git pull` بزنید. اگر با ZIP یا فلش آورده‌اید، پوشه را دوباره جایگزین کنید.
- پیشرفت مطالعه با به‌روزرسانی پاک نمی‌شود.

> ⚠️ **جابه‌جایی پوشه:** آیکون به مسیر پوشه اشاره می‌کند. اگر پوشه را جای دیگری بردید، نصب‌کننده (۲-۲) را دوباره اجرا کنید.
