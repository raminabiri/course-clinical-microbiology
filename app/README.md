# نرم‌افزار درس‌نامهٔ تعاملی میکروب‌شناسی بالینی تشخیصی

نسخهٔ تعاملی همین درس‌نامه که در پنجرهٔ مستقل، **بدون نصب و بدون اینترنت** روی ویندوز و لینوکس اجرا می‌شود.

> 📘 راهنمای گام‌به‌گام ویرایش و انتقال به کامپیوتر دیگر: [EDIT_AND_TRANSFER.md](EDIT_AND_TRANSFER.md)

## امکانات
- **درس‌ها:** همهٔ ماژول‌های ۰۱ تا ۲۴، آنتی‌بیوگرام (AST) و منابع مشترک، با فهرست مطالب، فلوچارت‌های قابل بزرگ‌نمایی، نشان‌گذاری، یادداشت شخصی و علامت «خوانده‌شده».
- **آزمون تصویری:** بیش از ۵۰۰ پرسش از عکس‌ها و دیاگرام‌های درس‌نامه، شامل شناسایی ارگانیسم و تفسیر تصویر.
- **مرور هوشمند:** پرسش‌هایی که نادرست پاسخ داده‌اید، با فاصله‌های ۱، ۲، ۴، ۸ و ۱۶ روز دوباره نشان داده می‌شوند (روش لایتنر).
- **سناریوهای بالینی:** ۳۳۰ سناریو با پاسخ مرجع. پاسخ خود را بنویسید و خودتان یا Claude آن را ارزیابی کند.
- **اطلس تصاویر:** همهٔ تصاویر با زیرنویس، منبع و مجوز، قابل جست‌وجو و بزرگ‌نمایی.
- **فیلم‌های آموزشی:** فیلم‌های YouTube برای هر ماژول، که پیش از افزودن، وجود هر کدام بررسی شده است. برای تماشا به اینترنت آزاد نیاز است.
- **✦ پرسش از Claude:** کنار هر عنوان، دکمهٔ «✦ بپرس» هست و در هر صفحه دکمهٔ «پرسش از Claude». Claude با متن همان بخش به فارسی پاسخ می‌دهد.
- جست‌وجوی سراسری، پوستهٔ روشن و تیره، تنظیم اندازهٔ متن، چاپ یا ذخیرهٔ PDF هر صفحه.

## اجرا

### ویندوز
1. یک‌بار روی `install-windows.bat` دوبار کلیک کنید تا میان‌بر «میکروب‌شناسی بالینی تشخیصی» با آیکون روی **دسکتاپ** و در **منوی Start** ساخته شود.
2. از آن به بعد با همان آیکون اجرا کنید. بدون ساختن میان‌بر هم می‌توانید `start-windows.bat` را اجرا کنید.

برنامه در پنجرهٔ مستقل Microsoft Edge (یا Chrome) باز می‌شود و نصب چیز دیگری لازم نیست.

### لینوکس
```bash
cd app
./install-linux.sh     # آیکون در منوی برنامه‌ها و روی دسکتاپ
./start-linux.sh       # اجرای مستقیم
```
برنامه از Chrome، Chromium، Edge یا Brave استفاده می‌کند. اگر هیچ‌کدام نصب نباشد، در مرورگر پیش‌فرض باز می‌شود.

## انتقال به رایانهٔ دیگر
- **با GitHub:** `git clone https://github.com/raminabiri/course-clinical-microbiology.git` و سپس اجرای نصب‌کنندهٔ همان سیستم‌عامل.
- **با هارد یا فلش:** کل پوشهٔ مخزن را کپی کنید و نصب‌کننده را دوباره اجرا کنید.
- اگر پوشه را جابه‌جا کردید، نصب‌کننده را دوباره اجرا کنید تا میان‌بر به مسیر تازه اشاره کند.
- **پیشرفت شما** (صفحه‌های خوانده‌شده، نشان‌ها، یادداشت‌ها، نتایج آزمون) فقط روی همان رایانه ذخیره می‌شود. برای انتقال: **تنظیمات ← ذخیرهٔ فایل پیشرفت** و در رایانهٔ دیگر **وارد کردن فایل**.

## پرسش از Claude و هزینه
- هر خواننده **کلید API خودش** را در **تنظیمات** وارد می‌کند و هزینه از حساب خود او کسر می‌شود. کلید را از [console.anthropic.com](https://console.anthropic.com/settings/keys) بسازید.
- کلید فقط روی همان رایانه ذخیره می‌شود و مستقیم به `api.anthropic.com` فرستاده می‌شود. در مخزن، GitHub یا فایل پیشرفت ذخیره نمی‌شود.
- مدل پیش‌فرض **Claude Opus 5.5** است. در تنظیمات می‌توانید Sonnet 5.5 (ارزان‌تر) یا Haiku 5.5 (ارزان‌ترین) را انتخاب کنید. هزینهٔ تقریبی هر پاسخ زیر همان پاسخ نشان داده می‌شود.
- برای کنترل هزینه، در کنسول Anthropic سقف مصرف ماهانه تعیین کنید.
- این بخش به اینترنت نیاز دارد. بقیهٔ برنامه آفلاین کار می‌کند.

## به‌روزرسانی محتوا (برای نگهدارندهٔ مخزن)
برنامه محتوا را از فایل `assets/js/content.js` می‌خواند. پس از ویرایش هر فایل Markdown یا افزودن تصویر، این فایل را دوباره بسازید:
```bash
python3 app/build/build_content.py
```
- فقط Python 3 لازم است و به بستهٔ دیگری نیاز ندارد.
- پرسش‌های تصویری از جدول‌های `Assets/CREDITS.md` و سناریوها از فایل‌های `*_Scenarios.md` و `*_Answers.md` ساخته می‌شوند.
- فهرست فیلم‌ها در `assets/js/videos.js` است و دستی ویرایش می‌شود.
