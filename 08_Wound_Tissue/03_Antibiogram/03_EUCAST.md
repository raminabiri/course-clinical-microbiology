# آنتی‌بیوگرام — زخم، بافت، استخوان، ایمپلنت بر اساس EUCAST

> **مرجع:** EUCAST Breakpoint Tables (نسخهٔ جاری). ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. نکات ویژه
| موضوع | EUCAST |
|---|---|
| **ریفامپیسین** (استافیلوکوکوس) | نقطهٔ برش بالینی (با پانویس استفادهٔ ترکیبی) |
| **فوزیدیک اسید** | نقطهٔ برش (کاربرد ترکیبی در اروپا برای عفونت استخوان/ایمپلنت) |
| **فسفومایسین وریدی** | نقطهٔ برش فقط برای *E. coli* در میان Enterobacterales (v16.1؛ [AST](../../AST/09_Breakpoints/01_Gram_Negative.md))؛ برای استافیلوکوکوس AST توصیه **نمی‌شود** (فقط درمان ترکیبی؛ راهنمای EUCAST) |
| **بی‌هوازی‌ها** | جدول اختصاصی شامل *C. acnes* (بنزیل‌پنی‌سیلین، کلیندامایسین، ونکومایسین، ریفامپیسین…) و روش دیسک FAA-HB |
| *Corynebacterium* | جدول اختصاصی |
| *Kingella kingae* | جدول اختصاصی |
| *P. aeruginosa* | «I» = دوز بالا (سیپروفلوکساسین ۷۵۰ mg × ۲ خوراکی) |
| *Aerococcus* | جدول اختصاصی |

## ۲. انتخاب بر اساس عوامل بیمار
همانند CLSI (فایل [02_CLSI.md](02_CLSI.md)، بخش ۲). در اروپا ترکیب‌هایی مانند **ریفامپیسین + فوزیدیک اسید** (خوراکی) برای استافیلوکوکوس ایمپلنت رایج است و EUCAST برای هر دو نقطهٔ برش دارد.
